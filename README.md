# Foodplan

**Web application to organize weekly family meals with real Chilean recipes**  
Helps families simplify planning, adjust portions, and generate ingredient shopping lists automatically.

---

## Overview

Foodplan is a **modular web application built with Flask (Python)** that supports weekly menu planning with editable meals and portion-based ingredient calculations.  

This project focuses on:
- Simplifying meal organization for families  
- Automatically generating a shopping checklist based on recipes and servings  
- Enabling complete customization of weekly menus  

---

## Features

- Default weekly menu assigned when a user is created (fully customizable)  
- Recipes based on common Chilean meals  
- Ingredient quantities recalculated dynamically based on servings (1–9)  
- Automatic **shopping checklist** with item+quantity aggregation  
- User authentication and session management  
- SQLAlchemy ORM for recipe and ingredient data  
- Database migrations via Flask-Migrate  
- Clean, responsive UI with HTML, CSS, and JavaScript
